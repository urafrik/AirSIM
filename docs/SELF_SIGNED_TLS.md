# 自签 TLS 证书与客户端指纹固定

远程直连支持自签证书，使用**服务器叶证书 DER 内容的 SHA256 指纹**固定身份。指纹不是证书文件文本的哈希，也不是公钥 SPKI 哈希。

本次本地生成的证书用于 `vip.gz.frp.one`。新版 iPhone 设置页预填该域名和对应公开指纹；私钥不在 GitHub、源码包或 IPA 中。

## 使用本次交付的证书

1. 将本地证书交付包里的 `fullchain.pem` 和 `privkey.pem` 放到内网电脑 `C:/AirSIM/certs/`，不要上传到 GitHub 或 frps。
2. 使用现有 stunnel 配置，两个端口均使用这一套证书。frpc 继续使用 TCP 类型透传，不终止或替换证书。
3. 安装新编译并自行签名的 IPA，先完成安卓本地配对。在 frp 直连设置中，域名填写 `vip.gz.frp.one`，控制和音频端口填你实际分配的 frp 公网端口。
4. “证书 SHA256 指纹”与交付包 `certificate-sha256.txt` 一致后保存。默认端口 17592/17593 只是示例，第三方 frp 服务不一定允许使用。

不需要购买域名、不需要 ACME 验证域名所有权，也不需要在 iPhone 上安装根证书或开启系统的完全信任。TLS 仍需校验证书指纹、域名、用途与有效期；指纹不匹配时不回退成接受任意证书。

## 重新生成或更换证书

在自己的电脑执行（需要 Python 3、OpenSSL）：

```sh
python deploy/direct-frp/generate_self_signed.py --host vip.gz.frp.one --out ./my-private-certs
```

脚本生成 365 天自签证书、RSA 3072 位私钥和公开指纹；拒绝覆盖已有证书，避免意外更换服务器身份。保管私钥，仅复制公开指纹到 iPhone。获取指纹时应使用本地证书文件，通过可信渠道传递，不能直接信任第一次公网连接给出的指纹。

也可自行计算：

```sh
openssl x509 -in fullchain.pem -noout -fingerprint -sha256
```

在 App 中只粘贴指纹十六进制值，可包含冒号、空格或大小写，不包含 `sha256 Fingerprint=` 前缀。更换证书（即使复用同一私钥）也必须更新指纹；指纹与当前保存端点绑定，通话中禁止修改配置。若要换域名/IP，需要新证书包含对应 SAN。

留空指纹时仍按系统公共 CA 规则验证，自签证书会被拒绝；这不是“跳过证书验证”开关。旧版公开 CA 配置保持兼容。Watch 音频也接收并验证同一指纹，需升级配套 Watch App。

GitHub Actions 会用临时证书和回环 TLS 服务检查正确指纹成功、错误指纹/域名失败、不固定指纹时拒绝自签证书，以及证书过期和 Watch 参数传递。CI 使用独立测试密钥，不使用本次用户私钥。

自签证书仅改变 TLS 信任方式；仅直连仍不能保证 iPhone 被挂起或终止后收到后台来电。
